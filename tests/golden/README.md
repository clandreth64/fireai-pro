# Golden drawing tests

Each drawing in `drawings/` with a matching `expected/<stem>.json` is run through the
full drawing-understanding pipeline by `tests/test_golden.py`, and the result is
compared with the expectations.

## Adding a real drawing (anonymized DWG/DXF)

1. Remove client names, addresses, and title-block content you are not allowed to keep
   (or get written permission). Never commit confidential customer drawings.
2. Copy the file to `drawings/<descriptive_name>.dxf` (or `.dwg`).
3. **Open the drawing in CAD yourself** and write `expected/<descriptive_name>.json` from
   what *you* see — not from FireAI's output. Only assert what you have verified.
4. Run `pytest tests/test_golden.py -k <descriptive_name>`.
5. Review `overlay.png` for the case (pytest `--basetemp` keeps outputs) before committing.

DWG cases are skipped automatically unless a DWG converter is installed
(`FIREAI_DWG_CONVERTER`, `ODAFileConverter`, or `dwg2dxf` on PATH), unless the
expectation is the explicit `DWG_CONVERSION_UNAVAILABLE` failure.

## Expectation keys (all optional except `processing_status`)

| key | meaning |
|---|---|
| `processing_status` | `completed` / `needs_human_input` / `failed` |
| `failure_code` | expected failure code, or `null` |
| `units` | resolved unit (`in`, `ft`, `mm`, `cm`, `m`) |
| `units_override` | pass this unit override to the pipeline |
| `bounds_ft` | `{"width": w, "height": h, "tol": t}` normalized extents |
| `entity_counts` | `{"top_level": n, "total": n}` exact counts |
| `element_counts` | `{"room": 3, "door": 3, ...}` exact counts per category |
| `min_element_counts` | `{"wall": 10}` lower bounds |
| `rooms` | `[{"label": "...", "area_sf": a, "tol": t}]` rooms that must exist |
| `text_contains` | strings that must appear in extracted text |
| `review_triggers_include` / `review_triggers_exclude` | trigger codes |
| `requires_human_review` | expected boolean |
| `skip_if_dwg_converter_available` | for the no-converter failure case |

The `synthetic_*` drawings are generated by `scripts/generate_golden_fixtures.py`
and their expectations were written from their known construction.
