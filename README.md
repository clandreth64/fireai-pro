# fireai-pro
Backend repo (FastAPI) — Description  Private backend for FireAI Pro: FastAPI service that runs the FireAI orchestrator (routing, hydraulics, codes, BOM) and returns DXF/IFC/PDF deliverables.  Frontend repo (Next.js) — Description  FireAI Pro UI: Next.js (TypeScript) app to upload drawings, start runs, track job status, and download DXF/IFC/PDF
